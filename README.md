# NERO PROJECT

### Digital Studio — Diseño, Arquitectura e Identidad Digital

Nero Project es un sitio web desarrollado como proyecto de portfolio para un estudio digital ficticio enfocado en **diseño web, arquitectura digital, identidad de marca y estrategia digital**.

El proyecto busca presentar una experiencia visual moderna, minimalista y editorial, combinando una estética profesional con animaciones e interacciones desarrolladas con JavaScript.

---

## ✦ Vista general

Nero Project está compuesto por una página principal y diferentes páginas dedicadas a los servicios y proyectos del estudio.

El sitio incluye:

* Página principal.
* Sección de introducción.
* Portafolio de proyectos.
* Sección de servicios.
* Páginas individuales para cada proyecto.
* Páginas individuales para cada servicio.
* Formulario de contacto funcional.
* Integración con Formspree.
* Navegación responsive.
* Menú mobile.
* Animaciones al hacer scroll.
* Efecto parallax en el hero.
* Navegación activa según la sección visible.
* Enlaces a perfiles profesionales de Behance y LinkedIn.

---

## 🛠️ Tecnologías utilizadas

### HTML5

Utilizado para construir la estructura semántica del sitio:

* Header
* Navegación
* Hero
* Secciones
* Portafolio
* Servicios
* Formulario de contacto
* Footer

### CSS3

Utilizado para desarrollar la identidad visual y el diseño responsive:

* CSS Grid
* Flexbox
* Variables CSS
* Media Queries
* Animaciones
* Transiciones
* Diseño responsive
* Efectos visuales
* Tipografía editorial

### JavaScript

Utilizado para agregar interactividad y comportamiento dinámico:

* Menú mobile.
* Scroll suave.
* Navegación activa.
* Animaciones mediante `IntersectionObserver`.
* Efecto parallax.
* Validación del formulario.
* Envío del formulario mediante `fetch()`.
* Integración con Formspree.

### Formspree

El formulario de contacto utiliza **Formspree** para procesar y enviar los mensajes enviados desde el sitio.

## 📌 Secciones principales

### Inicio

Presentación principal del estudio con una introducción visual y llamada a la acción.

### Introducción

Explica el concepto de Nero Project y su enfoque en la creación de estructuras digitales.

### Portafolio

Presenta diferentes proyectos desarrollados por el estudio:

* **Identidad Editorial**
* **Arquitectura Web**
* **Estrategia Digital**

Cada proyecto cuenta con su propia página para mostrar información y contenido adicional.

### Servicios

El sitio presenta cuatro áreas principales:

1. Arquitectura Digital
2. Diseño Web
3. Identidad de Marca
4. Estrategia Digital

Cada servicio dispone de una página individual.

### Contacto

La página incluye un formulario mediante el cual los visitantes pueden enviar:

* Nombre
* Correo electrónico
* Empresa
* Mensaje

Los datos son enviados mediante Formspree.

## ⚡ Funcionalidades JavaScript

El proyecto utiliza JavaScript para mejorar la experiencia de navegación.

### Menú responsive

Permite abrir y cerrar el menú de navegación en dispositivos móviles.

### Scroll suave

Los enlaces internos realizan un desplazamiento suave hacia las diferentes secciones.

### Navegación activa

El enlace correspondiente a la sección visible se marca automáticamente mientras el usuario navega.

### Animaciones

Los elementos aparecen progresivamente al entrar en el viewport mediante `IntersectionObserver`.

### Parallax

El hero incorpora un efecto de movimiento sutil al realizar scroll.

### Formulario

El formulario cuenta con:

* Validación de campos obligatorios.
* Validación del correo electrónico.
* Mensajes de éxito.
* Mensajes de error.
* Estado de envío.
* Envío real mediante Formspree.
