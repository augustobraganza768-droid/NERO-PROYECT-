Identidad Editorial

Desarrollo de una identidad visual contemporánea, elegante y adaptable para una marca con una fuerte orientación editorial.

SOBRE EL PROYECTO

Una identidad con propósito.

El proyecto nació con el objetivo de construir una identidad visual capaz de transmitir sofisticación, claridad y personalidad.

Se desarrolló un sistema gráfico compuesto por tipografía, composición, color y recursos visuales capaces de adaptarse a distintos formatos.

La dirección creativa busca generar una experiencia visual consistente tanto en medios digitales como físicos.
